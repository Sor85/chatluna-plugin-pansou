# tests 说明

适用范围：`tests/`。同时遵守根 `AGENTS.md`；行为契约见 `src/AGENTS.md`。

- 单元与集成测试在 v2 的 `external/pansou` 副本运行，不在独立源码目录安装依赖。
- 覆盖当前插件的默认配置、API 请求/响应、搜索参数、后端过滤透传、重复项保留、截断、后端缓存刷新、超时、错误与工具契约；测试真实行为，不复制被测算法。不要求兼容旧配置键或非当前协议的响应，回归测试须验证其不会重新引入。
- HTTP 测试使用本地临时监听器，不依赖公网搜索服务或用户数据；请求取消、错误响应和缓存需可重复验证。
- OneBot 沙盒验收使用新建独立空间，显式传 `spaceId`，不在主环境发消息、改用户权限或清空历史。完成后 complete/fail 空间、停止本轮机器人并保留测试证据；仅清理本轮临时服务和自建预设，不删除空间或用户数据。
- 测试 token 从环境变量读取，不写测试 fixture、快照或报告。浏览器验证只在用户要求时运行，结束关闭会话并清理工具临时文件。
- 发布脚本回归使用临时源码/宿主目录和替身 CLI，通过真实子进程执行脚本；不得访问真实 npm、创建真实远端标签或改动用户 Git 状态。覆盖演练、正式发布检查、产物清理、失败中止与发布后标签顺序。
- 守卫测试检查根 AGENTS.md 清单与实际子目录说明双向一致，并检查插件未重新暴露 toolName/toolDescription 配置。
