# src 说明

适用范围：`src/`。同时遵守根 `AGENTS.md`；回归测试见 `tests/AGENTS.md`。

- `index.ts` 只声明与组装插件；配置在 `config.ts`，HTTP 边界在 `client.ts`，响应规范化与文本输出在 `utils.ts`，工具定义在 `tool.ts`，共享类型在 `types.ts`。
- 插件只提供模型工具，不新增聊天命令、本地缓存、重试、去重或搜索页面。`conc`、`refresh`、`filter` 与类型筛选透传 PanSou，不在插件内另行执行。
- PanSou 地址来自管理员配置，支持内网 HTTP(S) 和反向代理路径；搜索输入不得覆盖地址、凭据或超时。禁止带内嵌凭据/查询/片段的地址，HTTP 重定向明确失败，不转发令牌。
- `defaultCloudTypes` 是可覆盖默认值，不是白名单；显式空数组覆盖为全部，省略使用配置。`maxResults` 同样是默认总展示量，单次可在 1–20 内覆盖。
- 分类限量直接使用 PanSou 网盘类型键（包括 `115`/`123`），不保留旧键 `pan115`/`pan123` 或迁移映射，避免维护两套名称；0 不单独限制。先按分类裁剪，再按总量裁剪，保留后端顺序与重复结果。
- 合并结果有有效链接时不混入原始结果；否则从 `results[].links` 回退。标题中的数量是分类裁剪后数量，不使用后端 `total`。
- 只解析当前 PanSou 的 `{ code: number, data: ... }` 包装响应，不接受裸响应或字符串错误码。响应视为不可信数据；非零错误码无论是否带 data 都失败，结构错误不伪装为空结果。普通 HTTP/后端错误继续返回中文错误文本，调用取消和卸载取消抛回 v2，不伪装成功。
- 不记录响应正文或 token；交给模型的错误文本先脱敏再截断。结果中的分享提取码属于插件业务输出，不视为认证令牌。
- `pansou_search` 是只读工具，直接用 v2 `ctx.tools.define` 注册，名称固定、默认描述随定义提供；用户策略和描述覆盖交给 v2 管理，不添加插件级元数据配置。
- 配置用 `@chatluna/schema` 描述，字段显式写中文 label；宿主 ui-kit / SchemaForm 负责控件、校验、保存及工具调试，不自建客户端入口。checked 包装在服务端参与校验，而表单渲染 inner，字段默认值和文案在两层都需保留。
- 请求超时、v2 工具取消和 Cordis fiber 卸载都必须终止当前请求；定时器在结束后释放。
